# 歌词工作台：从查词到同步试听

保留 Vite + React、Fastify 和 pnpm，以及现有采集限流、匹配和导出。开发端 `9117`、生产端 `9120` 不变。

- 搜索按钮名不变，结果区反馈等待、无结果和重试。Enter 走表单提交，中文输入法组字不额外触发搜索。唯一精确姓名或别名直接展开，模糊命中由用户选择。点曲名查单曲，复选框只用于批量。
- 文件、文件夹都可导入，读取音频标签与时长，音频不上传。使用浏览器 IndexedDB 保留本地曲库、音源绑定和确认过的歌词；浏览器清理数据会移除这些副本，不影响原文件。不同端口是独立存储来源。
- 以录音 ID 管理绑定。ISRC 一致且时长不冲突优先；标签证据充分且无同名版本竞争时才自动配对。文件名或少量匹配证据只给候选，支持手动覆盖，不强合并同名录音。
- 在线音源首版为用户提供的授权音频播放直链，浏览器直接请求，不代理、不抓取、不承诺覆盖商业曲库。片段或时长不符只能试听，不启用整首时码。无音频时仍可阅读和导出歌词；导出不包含音频。
