# 不可播放曲目的有界跳过

**依据：** PRD R-06。沿用 Swift 原生 monorepo、现有播放器界面和 V2 快照；不改曲库及音频文件。

- [x] 先用合成 WAV、损坏音频和可控制的 resolver 复现故障：自然推进、暂停导航、候选耗尽、恢复重试和迟到结果。
- [x] 在 `PlaybackQueue` 中维护一次性的遍历状态。下一首按 replay → 待播 → 最多一次列表循环遍历；上一首按实际历史。每个曲目 ID 本次最多探测一次。只有候选准备好才提交所选曲目和队列；不把失败候选记入历史，不永久删除曲目，不改变快照格式。
- [x] `Player` 统一处理 resolver、AVPlayerItem 起播错误和取消；暂停时允许检测候选但不出声；显式暂停、重新选曲及队列变更取消尚未提交的导航。直接点播或恢复失败保留原曲及进度；播放中读失败不自动换曲；音频会话激活失败不视作坏曲候选。
- [x] 迷你条与全屏页提示「已跳过 N 首」或「没有可播放的歌曲」，耗尽后支持重新尝试原导航；保持简中、英语及现有控制。
- [x] 运行定向与全量检查；在可用时以独立 Mac 测试版复验合成曲库。记录实际结果，区分 iPhone 构建和真机验收。

## 实际结果

- 首轮新增的 5 个场景在旧实现上均失败；实现后全部通过，并补上单曲循环失败的回归。
- `scripts/check.sh` 退出码 0：37 个 XCTest、macOS、通用 iOS 设备（未签名）和 iOS 模拟器构建通过。Mac 独立版确认暂停时跳过缺失文件、列表循环耗尽停止、恢复文件后可从「重试」播放。
