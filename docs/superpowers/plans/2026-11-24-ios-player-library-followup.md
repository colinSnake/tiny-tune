# iOS 播放、曲库与通屏背景修复

- [x] 用用户提供的音频目录只读核对路径、文件标签与时长。在 Swift 包内用合成 Track 验证同目录、同曲、明确音质后缀的版本折叠，以及不同目录、录音和路径保留。只改 iOS 浏览投影，底层来源、原有队列/歌词 ID 和源文件不变。
- [x] iOS 歌手/专辑/歌曲切换时重建滚动容器而不是复用旧偏移；减少该页嵌套惰性布局，保留详情导航与歌曲排序。对定位范围作静态回归，设备可用时用长列表复测。
- [x] 从已确认山水稿延伸通屏浅/深色 SVG，音乐库、搜索、来源共享同一个原生背景组件；标题居中、来源正常状态和扫描不重复放在列表，异常和更多操作仍可访问。
- [x] iOS 正在播放采用居中唱盘、缩小且对准沟槽的唱针、居中曲目信息、唯一一组上一首/播放/下一首；播放顺序和队列独立为有文字的第二排；无歌词仅显示状态，读取失败仍可重试。
- [x] 先跑新增失败回归，再定向清洁后编译/测试；不碰手机个人曲库、工作区其他修改或用户音频，不提交。

- 实现及自动化完成：98 个 XCTest（启用真实目录报告）和 11 项结构检查通过，iOS Simulator／iPhoneOS／macOS 清洁构建通过，`git diff --check` 通过。

- 没有提交、推送或覆盖个人手机 App；工作区既有修改保留。完整命令、警告和抽查边界见 `docs/native-development-validation.md` 同日追加修复。
