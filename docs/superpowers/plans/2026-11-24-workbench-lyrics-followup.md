# Web 查词与歌词面板修复计划

目标：搜索后自动为当前歌曲查词，修复 B 站分集元数据阻断；保留等高工作区，恢复山水横幅、标题字体并移除搜索框双层焦点轮廓。

- 先用实际分集 API 确认空歌手和原始标题导致跳过，再添加 B 站目录、查词 API、客户端详情及静态布局回归。
- 从分集标题拆出明确署名、清理曲序；支持邓紫棋中英文别名和歌词库的双语标题。仅查询当前选中歌曲，依然可取消旧请求；严筛歌名歌手，不以时长相近证明 B 站音源已同步，不自动给下载附加歌词。
- 右栏拆为紧凑曲目信息／试听与独立歌词卡，版本、状态、重新查词归入歌词区。来源播放器需点开，限制展开高度，保留阅读空间。
- 复用 `public/landscape.svg` 和本地软糖字体路由，不复制字体；只用单层边框反馈输入框焦点，保留按键焦点可见。
- 清理对应构建产物后跑全量测试、生产构建；使用 9117 实测邓紫棋首选和切歌，检查桌面和窄屏。验证只读，不写真实曲库，不提交。
