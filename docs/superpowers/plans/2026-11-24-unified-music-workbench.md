# 歌曲与歌词统一工作台实施计划

**Goal:** 一次搜索，左侧歌曲列表，右侧试听和歌词，一键保存或导出，不再切换歌词工具。

**Architecture:** 复用本地曲库、MusicBrainz、歌曲来源、授权下载、安全 sidecar 写入 API。统一入口和请求生命周期；本地版本时长冲突时只允许显式保存不带时间轴的文本，不伪造同步。

**Tech Stack:** React / TypeScript / Fastify / node:test / Playwright CLI。

**Spec:** 本轮用户明确的左右布局与极简操作要求。

## 约束
- 保留工作区已有更改；不提交、不推送。
- 不更改音频，不覆盖现有歌词，不把不匹配的时间轴写入本地。
- 本地目录取服务端配置；浏览器不得提交任意文件路径或下载 URL。
- 验收用隔离原创曲库；真实曲库只读复核。
