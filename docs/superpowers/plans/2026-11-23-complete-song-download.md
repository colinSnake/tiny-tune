# 整曲与歌词下载实施计划

依据同日的已确认设计。在现有工作树中增量实现，不提交、不变更原生端或旧采集端口。

1. 在 `tools/LyricsWorkbench/test/songs.test.ts` 先固定契约：搜索、详情、同名 MP3/LRC/清单 ZIP，按 ID 重查授权，拒绝缺词、版本冲突、部分音频及越界跳转。执行测试观察失败。
2. 新增 `src/song-types.ts` 和 `src/songs.ts`，注册 `/api/songs` 搜索／详情／下载路由。默认只接明确授权的来源；Jamendo 自带曲目下载标志并不等于允许离线打包，保留单独的部署授权开关和审批曲目表。复用限流、LRC 解析和文件命名；核对实际媒体内容，再生成 ZIP。
3. 新增下载首页和样式。用 Enter/按钮发同一个搜索请求，展示录音、来源、歌词状态、试听和 ZIP 动作；旧工作台用 `?view=lyrics` 保留。切换结果取消过期请求；失败内联反馈。
4. 更新 README、`.env.example`，验证 `pnpm test`、`pnpm build`、`git diff --check`，在浏览器验证正常、异常及窄屏布局。真曲目仅在独立验证授权及可用性后启用；无真实配置时以受控夹具验证，不将其宣称为线上源。
