# 音乐工作台：统一搜索与一键下载

- 先用固定曲目核对候选来源的真实响应、原版匹配、整曲下载标志及歌词覆盖。未验证音频和歌词打包许可的来源不接为下载源。
- 保留现有整曲 ZIP 复核逻辑。将主搜索拆成独立来源请求，按可操作状态合并排序，不让慢来源拦住快结果。接入已有 LRCLIB 搜索作为明确标注的「仅歌词」候选；不猜测它和其他音源是同一录音。
- 只有唯一精确命中才自动打开；已确认可下载的录音在列表直接下载，不增加歌词工作台或上传步骤。保留手动版本选择、失败重试及骨架屏。
- 用固定源测试、真实曲目搜索、下载 ZIP 校验及桌面/窄屏浏览器验证；记录没达到的华语整曲覆盖，不提交第三方素材。
