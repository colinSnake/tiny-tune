# 歌曲与歌词工作台 UI 验收

日期：2026-11-24。范围：本轮 Web 布局、两行歌曲行、图标操作及滚动范围；未修改或验收原生 App。

## 设计对照与结论

- 参考：仓库 `.local/workbench-design-v2/desktop-lyrics.jpg`。
- 同尺寸实现：`.local/workbench-v2-qa/desktop-reference-size.jpg`；并排对照：`.local/workbench-v2-qa/design-comparison.jpg`。两图均为 1265 × 1010 px，无截图缩放；已选歌曲、歌词可用且暂停，验收数据替代参考曲目。
- 实际视口另验 1280 × 720 与 390 × 844 CSS px，截图也是同等像素尺寸。
- 字体：沿用产品系统字体，歌名与歌手分两行；长标题单行省略，不挤占固定时长及图标。保留产品字标，不引入新字体或图像资产。
- 布局节奏：保留顶部独立操作条与左右两栏；按最新需求压缩页头并填满视口，桌面两栏上下边缘一致，窄屏改为上下分区。
- 颜色：保留白色面板、浅灰绿画布和深绿操作色；选中行浅绿，图标默认透明，悬停／聚焦出现浅绿底。
- 素材质量：复用现有产品图标，不新增位图素材；现有歌曲占位符与设计稿的细节差异不属于本轮修改范围。
- 文案：显示真实歌名、歌手、时长、下载状态；不把“可下载”误标成“已下载”。来源权限和时间轴不匹配提示继续保留。
- 有意差异：新增行级图标、下载状态和 4px 内部滚动条；歌词保留现有可点击时间码展示，不伪造设计稿中的歌词内容或播放状态。

## 已修复问题

- P2：旧 `.wb-row-main` 的 `flex-direction: column` 导致时长落到文字下方。新样式显式重置为 `row`，增加回归测试并在浏览器确认两行文字与时长并列。
- 默认图标底色透明；鼠标悬停或键盘聚焦时才显示背景。不可用来源禁用下载与试听，并保留无障碍标签。
- 页面无横向／纵向外层滚动；只有歌曲列表显示滚动条，歌词和详情保留隐藏滚动条的内部滚动能力。

## 实测

- 1280 × 720：文档尺寸 1280 × 720；桌面左右面板均从 y=252 到 y=690，高度 438。
- 长列表：内容 2565px、可视高度 340px；WebKit 滚动条宽高实测均为 4px。Firefox 使用 thin 回退，不能承诺原生滚动条精确 4px；未在 Firefox 实机验收。
- 390 × 844：文档尺寸 390 × 844，无页面溢出；时长及两个行级图标保持在行内，长歌名只有一行。
- 行级试听 → 暂停 → 试听：音频 paused 与 aria-pressed、图标一致。
- 行级音频和歌词 ZIP 下载成功，“未下载”转为“已下载”；再保存到已有文件的隔离曲库，显示跳过且未覆盖。
- 下载 ZIP 与直接保存的 MP3 均与生成的原创验收音频逐字节一致。测试写入仅在 `.local/workbench-v2-qa/library`，未写入用户真实音乐目录。
- `TSX_DISABLE_CACHE=1 pnpm test`：92/92 通过。
- `pnpm build`：通过（包含 `tsc --noEmit`、Vite、服务端打包）。构建前已停止对应验收服务并清理目标 dist 与编译缓存。
- 构建保留可选本机字体的运行时解析提示；缺少时回退系统字体，不影响本轮工作区。
- 证据均在被忽略的 `.local/workbench-v2-qa/`，不纳入提交。未创建提交或推送。

实际曲库只读复核：邓紫棋检索返回 95 行；两栏仍等高 438px，文档尺寸 1280 × 720，滚动条宽高 4px，音频处于暂停；浏览器未捕获 error 日志。生产预览保留在 9120。
